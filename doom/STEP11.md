## One mechanism, in both implementations

Keep six Doom tools and all definition bytes. More actions could allow new
button combinations, but all five current alternatives already rank first
at the qualified target. Their rejection happens after ranking. Changing tool
definitions would also change the field and invalidate the current state
identity, so it cannot isolate this cause.

In C `example_scores` and its Python counterpart, change only neural content
attention from an additive mixture of source and query coverage to:

```text
attention = (sum_example(weight * best_relation^2) / example_weight)
          * (sum_query(weight * best_relation) / query_weight)
```

Retain the existing zero guards. Both coverage directions must support an
example. No new coefficient, literal-text override, correction privilege,
tool-name rule or special Doom token is introduced. Keep field-mode scoring,
ordered-pair evidence, role/negation handling, six recurrent iterations,
reliability and every abstention/ambiguity threshold unchanged. Mirror the
one formula in `wolfe.py`, preserving the project's implementation parity.

This proposes a general scoring change, not a guaranteed fix. Argument payloads,
polite additions and paraphrases can add words without adding conditions;
existing slot, quote, filler and unknown-word treatment must face their tests.

## Fixed gate before adoption

1. Reproduce the incoming parent/candidate tables with the original C library.
   With a separately compiled candidate library, retain all 48 parent choices
   by `(status, calls)`. Each of the six sealed child states must realize its
   requested target choice and preserve the other 47 choices against the
   retained parent. Fresh-process reload must reproduce all 48 complete
   responses for each state. State bytes never change.
2. Add a small independent contract on neutral zero-argument tools amber and
   violet. A broad `sort cobalt parcel` example and a qualified
   `sort cobalt parcel urgent` correction must retain the broad action and
   emit the qualified action after reload. Preserve an unrelated anchor;
   unknown or quoted additions must not become the learned qualifier. Reverse
   tool/example order and exchange action labels without privileging names.
   Equal, identical construction examples with conflicting tools must remain
   ambiguous. With only urgent/routine alternatives and no broad default, an
   omitted qualifier must not produce a call. A qualified null correction must
   remain no_call. Record the original implementation's results before the fix.
3. Existing C and Python contracts, embedding checks, state interchange and
   seeded fuzz checks must pass. Existing full-JSON C/Python parity must pass
   for all 303 frozen fixture rows, three modes and three reasoning settings,
   with the existing 1e-6 tolerance. Keep source fixtures and expected answers
   fixed. Compare old/new neural decisions on the five existing fixture sets;
   no case correctly answered by the old implementation may become incorrect.
   Report the actual rows, not just an aggregate accuracy or script exit code.

The gate is conjunctive. An implementation error may be repaired to implement
the declared formula; an actual behavioral counterexample fails this mechanism.
Do not tune coefficients, thresholds, fixtures, examples or accepted outputs
after results, and do not try another scoring formula in this turn.
